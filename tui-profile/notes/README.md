# notes/ — TUI Profile 说明索引

本目录收录 **TUI Profile** 的说明文档：dsh-TUI 自身的插件准入要求与私有协议定义层。
它与 dsh-TUI 代码同处一库（`tui-profile/`），由 dsh-TUI 维护者随代码一并维护，并随
代码现状随时修订；它不是社区 RFC，不需要社区讨论、批准或"毕业"，也不是
`dsh-ecosystem-spec` 仓库的内容。

> 归属、修订方式、与上游 `dsh-std` 的边界与数据一致性要求以
> [`../governance/rules.md`](../governance/rules.md) 为准；本目录内的文档如何阅读、
> 编号怎么用，见 [0000-maintenance.md](0000-maintenance.md)。

**编号只是稳定锚点，不是 RFC 流程**：`0001`–`0008` 是文件名与交叉链接长期引用的固定
编号，用来保证仓库内外的链接可解析；编号顺序不代表提案顺序、成熟度或批准先后，
也没有对应的晋级阶梯。新增说明按需在末尾续号。
